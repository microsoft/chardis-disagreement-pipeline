# Confidence

For every individual concept annotation, assign a confidence rating from 1 to 5 based on how certain you are in that specific judgment.

Use the following scale for each concept:

1: Very Low Confidence  
 - The text is highly ambiguous, incomplete, contradictory, or confusing for this concept.  
 - You are unsure how the definitions apply.

2: Low Confidence  
 - The text is somewhat unclear or partially ambiguous for this concept.  
 - You can apply the definitions, but with notable uncertainty.

3: Moderate Confidence  
 - The text is mostly clear for this concept.  
 - Some ambiguity exists, but the definitions can be applied reasonably well.

4: High Confidence  
 - The text is clear and aligns well with the definitions for this concept.  
 - Only minor uncertainty remains.

5: Very High Confidence  
 - The text is very clear and unambiguous for this concept.  
 - You can apply the definitions with full certainty and no hesitation.

Return only the numeric value (1–5) for **each concept-level annotation**.
